# Astor 0.1.8 — exemples de formulations

| Demande | Réponse ou rôle |
|---|---|
| Donne-moi ton statut / Tu es là ? | État local du Hub |
| Peux-tu me donner l’heure ? / Il est quelle heure ? | Horloge du téléphone |
| Qu’est-ce que tu sais faire ? / J’ai besoin d’aide | Exemples de commandes |
| Montre mes notes / Ouvre mon coffre | État de la mémoire ; phrase secrète toujours exigée |
| Présente tes modules / Qui compose ton équipe ? | Liste des cinq rôles |
| Passe à Eve / Parle avec Hadès / Choisis Atlas | Choix du module s’il est activé |
| Je voudrais réviser l’anglais / Je veux comprendre les fractions | Eve : question de départ pour apprendre |
| Organise mon planning / Je veux définir mes priorités | Astor : objectif, moyens et échéance |
| Peux-tu vérifier cette affirmation : … / Contrôle cette idée : … | Atlas : analyse heuristique, pas validation factuelle |
| Pourquoi ? / Développe / Et après ? | Reprise du sujet local récent |
| Changeons de sujet / Repartons de zéro | Effacement du contexte temporaire |
| Présente-toi / Quel est ton rôle ? | Rôle et limites d’Astor |
| Quel est ton niveau de sécurité ? | Protections et limites du prototype |
| Tu m’entends ? / Comment utiliser le micro ? | Mode d’emploi de la dictée au toucher |
| Verrouille le coffre | Ferme la mémoire chiffrée |
| Ferme Astor / Verrouille la session | Verrouille le Hub |

Les demandes peuvent notamment commencer par « Peux-tu », « Pourrais-tu », « Pouvez-vous » ou se terminer par « s’il te plaît », « stp ». Les formes connues à l’infinitif sont rapprochées de leur commande : donner/donne, afficher/affiche, ouvrir/ouvre, choisir/choisis. Cela s’applique aux familles listées ; Astor ne comprend pas arbitrairement toutes les formulations.

La correction de « statue » reste limitée à une commande vocale courte sur une saisie vide. Aucun remplacement général dans les phrases. La reconnaissance française Android peut encore faire des erreurs : relire avant Envoyer.

La fonction demeure locale, fondée sur des règles et un contexte de quatre échanges. Elle n’ajoute pas de connaissances générales ou de moteur IA. Les réglages de sécurité et de microphone restent ceux de la version précédente.
