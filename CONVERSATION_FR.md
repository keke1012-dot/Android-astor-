# Essai rapide Astor 0.1.9

Envoyer dans cet ordre :

1. Je veux apprendre l’anglais
2. Je débute
3. Donne-moi un exercice
4. Plus simple
5. Un indice
6. La correction
7. Plus difficile

Pour changer de langue : Je veux apprendre l’espagnol.
Pour oublier : Changeons de sujet.
Pour répondre à un exercice : écrire le mot manquant ou Réponse : …

Le moteur local garde le sujet récent, pas un historique scolaire permanent. Les exercices sont préparés à l’avance. Le contexte disparaît au verrouillage.
