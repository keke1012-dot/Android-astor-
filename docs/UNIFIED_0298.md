# ASTOR 0.2.9.8 — Diagnostic ElevenLabs

Les échecs du service vocal affichent désormais le code HTTP, avec des indications pour les requêtes refusées, les accès, les limites et les erreurs du service distant. Aucun corps d’erreur distant ni clé API n’est affiché. Aucun nouvel essai automatique.

Cette mise à jour conserve l’identité Android et la signature de la version précédente. Elle améliore le diagnostic ; elle ne garantit pas l’accès à une voix ni le succès d’un appel authentifié.
