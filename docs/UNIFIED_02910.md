# ASTOR 0.2.9.10 — Réponses vocales automatiques

Lecture locale automatique des nouvelles réponses de conversation, activée par défaut. Aucun ancien message ni message d’accueil n’est relu. Lecture limitée aux 800 premiers caractères. Mode muet, arrêt, désactivation de la lecture automatique, verrouillage et arrière-plan annulent la lecture.

Profil Assistant plus grave, inspiré de JARVIS. Le choix de voix et de profil est conservé. Les noms explicitement masculins sont prioritaires ; Android ne normalise pas le genre de ses voix. Aucun genre n’est inventé pour les identifiants opaques. Le timbre masculin doit alors être choisi à l’écoute dans Voix ASTOR. Aucun modèle masculin indépendant n’est embarqué.

La mémoire et les réglages existants sont conservés, y compris le mode muet. Aucune clé API ni ElevenLabs.
