# ASTOR Unifiée 0.2.9 — version de test

Réunit RC1, S2 batch 64, interface mobile Internet, recherches Wikipédia avec confirmation Android, fichiers sélectionnés via Android, coffre chiffré, Mnémosyne, dictée, Atlas et Orpheus existants, Cognitive V1 et Learning V1, et politique réseau Hades.

Learning V1 conserve seulement des corrections confirmées pendant la session et les efface au verrouillage. Cognitive V1 est expérimental, désactivé par défaut, et effectue trois générations locales. Pour les longs contextes (>2200 caractères), le mode local simple prend le relais. Spotify reste à configurer ; aucune nouvelle intégration distante n'est annoncée opérationnelle.

La version installable de test utilise fr.astor.hades.unified.test.unified029, une signature de test et le débogage désactivé. Elle coexiste avec la RC1. Le modèle doit être installé dans cette application. Exporter une sauvegarde chiffrée de l'ancienne application et restaurer dans la nouvelle application vide pour transférer la mémoire. Ne pas désinstaller la RC1.

HTTPS imposé, certificats système uniquement, sauvegarde Android désactivée. Ces protections ne constituent pas une garantie d'inviolabilité. Vérifier sur Android 16 le coffre, les permissions, le verrouillage, Internet, fichiers et conversation avant une livraison stable. La clé privée RC1 n'est pas disponible dans cette compilation.
